# Shopen

A modern, multi-store e-commerce engine built with **Laravel 12**, **Vue 3**, **Inertia.js**, and **Server-Side Rendering (SSR)**.

## Overview

Shopen is a flexible e-commerce platform featuring an EAV (Entity-Attribute-Value) product model, multi-website/multi-store support, advanced pricing rules, and a full order lifecycle. It is designed to power scalable online shops with rich catalog management, promotions, and SEO capabilities.

## Tech Stack

- **Backend:** Laravel 12 (PHP)
- **Frontend:** Vue 3
- **Bridge:** Inertia.js (monolithic SPA without a separate API layer)
- **Rendering:** Server-Side Rendering (SSR) for SEO and fast first paint
- **Database:** MySQL / MariaDB
- **Media:** Spatie Media Library (`media` table)
- **Queues:** Laravel Queues (`jobs`, `job_batches`, `failed_jobs`)
